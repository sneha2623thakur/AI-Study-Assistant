# AI-Study-Assistant
AI Study Assistant :An AI-powered learning platform built for students, teachers, and parents.Built using React, HTML, CSS, Tailwind CSS, FastAPI, Ollama, and GenAI. React and Tailwind CSS power the frontend.One of the biggest challenges was formatting and structuring AI-generated responses.

An AI-powered study platform built to make learning simple, interactive, and accessible for students, teachers, and parents.

STUDENTS:
Get simple explanations, examples, study tips, quizzes, notes, and project guidance.
TEACHERS:
Verify facts and examples, explore different explanations, and create interactive learning activities.
PARENTS:
Get help with school projects, understand difficult topics, and support better study habits.

Tech Stack:
* React — Interactive frontend
* Tailwind CSS — Modern and responsive UI
* HTML & CSS — Structure and styling
* FastAPI — Backend and API handling
* Ollama — Local AI model integration
* GenAI — AI-powered responses and assistance

UI & Project Focus:
The project focuses on creating a clean, responsive, and user-friendly AI interface. A key challenge was handling and formatting AI-generated responses containing headings, lists, examples, and other structured content so they remain readable and visually consistent.

Goal:
To build a single AI learning companion that combines a modern UI with powerful AI capabilities to make studying and teaching more effective.
